# قاعدة بيانات مدرسة بلج بن عقبة للتعليم الأساسي

تطبيق ويب عربي (RTL) لإدارة بيانات الهيئة التعليمية والإدارية، مبني بـ **Streamlit** و **SQLite**.

## المحتويات
- `app.py` — واجهة التطبيق (لوحة معلومات، الكادر، الحافلات، الحراس والعمال، الممرضة، إدارة البيانات).
- `database.py` — طبقة قاعدة البيانات (SQLite): الإنشاء، القراءة، الحفظ، الاستعادة.
- `seed_data.py` — البيانات الأصلية المستخرجة من ملف بيانات الهيئة (2026/2027).
- `.streamlit/config.toml` — الثيم والألوان والخطوط.
- `school.db` — قاعدة البيانات الفعلية (تُنشأ تلقائياً عند أول تشغيل).

## التشغيل محلياً
```bash
pip install -r requirements.txt
streamlit run app.py --server.port 3001
```
على ويندوز: شغّل ملف `تشغيل_التطبيق.bat`.

## النشر
التطبيق منشور على Streamlit Community Cloud، ويُحدَّث تلقائياً مع كل `push` إلى هذا المستودع.
